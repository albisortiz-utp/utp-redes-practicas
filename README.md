#  Prácticas Académicas de Redes

**Estudiante:** Albis Ortiz  
**Universidad:** Universidad Tecnológica de Panamá (UTP)  
**Carrera:** Licenciatura en Ciberseguridad  
**Asignatura:** Redes de computadoras  

## 📌 Descripción

Este repositorio tiene como propósito documentar mis conocimientos y prácticas académicas relacionadas con las redes informáticas y el direccionamiento IP, desarrolladas durante mi formación universitaria en Ciberseguridad.

Aquí se recopilarán ejercicios, configuraciones, simulaciones y evidencias de las actividades realizadas utilizando Cisco Packet Tracer.

## 🎯 Objetivo

Documentar y organizar mis prácticas de redes, reforzando los conocimientos sobre conexión de dispositivos, direccionamiento IP y configuración básica de equipos de red.

## 🛠️ Herramientas utilizadas

- Cisco Packet Tracer.
- Computadoras y dispositivos de red simulados.
- Routers y switches.

## 📚 Temas y prácticas trabajadas

### 1. Creación de redes
- Creación de redes en Cisco Packet Tracer.
- Conexión de computadoras y dispositivos.
- Organización de dispositivos dentro de una red.

### 2. Direccionamiento IP
- Configuración de direcciones IP.
- Configuración de máscaras de subred.
- Identificación de direcciones de red y dispositivos.

### 3. Configuración de dispositivos
- Configuración básica de routers.
- Configuración básica de switches.
- Conexión de dispositivos de red.

### 4. Simulación de redes
- Simulación de comunicación entre equipos.
- Comprobación de conectividad.
- Observación del comportamiento de la red.

## 📁 Organización del repositorio

Los archivos de las prácticas se incorporarán progresivamente:

- `README.md`: documentación general del repositorio.
- `evidencias/`: capturas de las prácticas realizadas.
- `practicas/`: archivos y ejercicios de Cisco Packet Tracer.

## 📌 Estado del proyecto

Este portafolio académico se encuentra en desarrollo. Las evidencias y archivos de simulación se agregarán conforme estén disponibles.
